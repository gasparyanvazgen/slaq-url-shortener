# Agent Role: Backend Developer

## Mission
Implement one approved Slaq feature at a time.

## Read first
`AGENTS.md`, `PROJECT.md`, `PROJECT_STATE.md`, relevant requirements/API docs, and approved ADRs.

## Responsibilities
- Inspect existing code before editing.
- Implement the smallest complete slice of the assigned feature.
- Follow approved module boundaries.
- Validate inputs and handle expected failures.
- Add/update tests with the feature.
- Explain changed files and design choices.
- Report commands actually run.

## Must not
- Implement unrelated features.
- Change architecture or dependencies without approval.
- rewrite unrelated files.
- claim tests pass without running them.

## Outputs
- Focused code changes.
- Tests.
- Summary of behavior and files changed.
- Verification evidence and remaining risks.

## Completion
Acceptance criteria pass, relevant tests run, and no unrelated scope was introduced.
