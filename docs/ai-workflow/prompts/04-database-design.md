# Prompt 04 — Database Design and Persistence

Follow `docs/ai-workflow/agents/database-engineer.md`.

Use only the user-approved schema and architecture. Inspect current database code first.

Design or implement the SQLite schema and repository behavior for the assigned task. Use parameterized SQL and database constraints for uniqueness. Keep timestamps consistent in UTC. Consider atomic click increments and deterministic tests.

Before implementation, list the exact files to change and the tests. Do not add an ORM, migration framework, table, index, or dependency without explaining the need and obtaining approval.

Run relevant tests if possible and report exact commands/results.
