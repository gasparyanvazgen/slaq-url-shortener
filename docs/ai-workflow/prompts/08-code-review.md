# Prompt 08 — Review Current Changes

Follow `docs/ai-workflow/agents/code-reviewer.md`.

Review the current Git diff and relevant surrounding code against the approved architecture, requirements, and security guidelines.

Do not modify files during the review.

Report findings by severity:
- Critical
- High
- Medium
- Low
- Informational

For each finding include file/line, scenario, impact, and a concrete fix. Also report test evidence and areas not verified. Avoid speculative or purely stylistic comments.
