# ADR-018: Destination URL scheme allow-list, 2048-character cap, and credential rejection

- Status: Accepted
- Date: 2026-11-18
- Decision owner: User
- Register entry: D18 in [`DECISION-REGISTER.md`](DECISION-REGISTER.md)

## Context

A URL shortener stores a string and later places it in a `Location` header. Without a scheme
allow-list it becomes a script-injection and open-redirect vector; without a length cap it can
store unbounded data and emit oversized headers.

## Decision

- Accept only absolute `http:` / `https:` URLs.
- Maximum 2048 characters, measured **after** trimming.
- Store the value as submitted after trimming — no host lowercasing, no default-port removal, no
  trailing-slash normalization.
- Reject `javascript:`, `data:`, `file:`, protocol-relative values (`//host/path`), and anything
  unparseable with `400 VALIDATION_ERROR`.
- **Resolved sub-option:** reject URLs containing embedded credentials
  (`https://user:pass@host/`) with `400 VALIDATION_ERROR`.

## Alternatives considered

- **Normalizing URLs** (lowercase host, strip default ports): enables deduplication but changes what
  the user submitted.
- **A larger cap**: accommodates edge cases at the cost of storage and header limits.
- **`z.httpUrl()`**: additionally requires a registrable domain and would reject `localhost`, so
  plain `z.url()` plus explicit scheme and length checks is used.
- **Allowing credentials**: no supported use case, and it leaks secrets into logs and stats.

## Consequences

- The redirect is faithful to the submitted URL, and validation is explicit rather than relying on
  Zod's permissive `z.url()`.
- `localhost` and IP-literal destinations remain acceptable, which keeps local demos usable.
- The 2048 cap is the same bound used for `PUBLIC_BASE_URL` (D17), keeping limits consistent.

## Implementation impact

- `docs/security-guidelines.md` lists the rejected schemes and the credential rule.
- `docs/api-specification.md` states the field rules for `url`.
- `TASKS.md` §3 implements the checks and their tests; `docs/testing-strategy.md` enumerates the
  2048/2049 boundary and the rejected-scheme cases.

## Verification

Zod 4 `z.url()` permissiveness (it does not normalize or restrict schemes by itself) was
confirmed from the research pass on 2026-11-18. Not yet executed: no validation code exists.
