# Prompt 02 — Requirements and Acceptance Criteria

Follow `agents/project-manager.md`.

Turn the approved project brief into testable functional and non-functional requirements.

For each feature, specify:
- Inputs.
- Expected success behavior.
- Validation rules.
- Error cases and status codes.
- Data changes.
- Acceptance criteria.
- Tests needed.

Resolve contradictions by asking me. In particular, do not silently decide whether link deletion is in MVP. Update `docs/requirements.md` only after distinguishing confirmed requirements from proposals.
