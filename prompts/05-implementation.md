# Prompt 05 — Implement One Feature

Follow `agents/backend-developer.md`.

Feature to implement: [INSERT ONE APPROVED TASK]

First inspect the repository, relevant docs, and current Git diff. Then:
1. Restate the acceptance criteria.
2. Identify the smallest set of files to change.
3. Explain the approach briefly.
4. Implement only this feature.
5. Add or update focused tests.
6. Run relevant tests and type-check if available.
7. Report changed files, commands, actual results, and remaining issues.

Do not implement other roadmap items. Do not change approved architecture or dependencies. If a requirement is ambiguous, stop and ask.
