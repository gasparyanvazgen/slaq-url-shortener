# Prompt 07 — Debug a Defect

Follow `agents/backend-developer.md` and, where useful, `agents/qa-engineer.md`.

Bug report:
[PASTE ERROR, REPRODUCTION STEPS, AND EXPECTED BEHAVIOR]

Inspect relevant code and reproduce the issue before changing anything. Identify the root cause, not just the symptom.

Then propose the smallest fix, add a regression test, implement the fix after approval if it changes scope/design, and run the relevant tests. Report exact evidence and any unresolved uncertainty.
