# Prompt 09 — Documentation Update

Inspect the actual implementation and tests before writing documentation.

Update the README and API documentation to describe behavior that exists, not planned behavior. Include:
- Requirements and supported Node version if verified.
- Installation and run commands based on actual package scripts.
- Environment configuration.
- API endpoints and examples.
- Error responses.
- Test and type-check commands.
- Known limitations and deferred features.

Do not invent commands, environment variables, endpoint behavior, or test results. Clearly label anything not implemented.
