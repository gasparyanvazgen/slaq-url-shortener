# Code Review Workflow

Review the current diff against:
- Approved architecture.
- Functional requirements.
- TypeScript strictness.
- Input validation and URL protocol restrictions.
- Parameterized SQL and database constraints.
- Error contract.
- Redirect and click-count semantics.
- Expiration boundaries.
- Tests and documentation.

Report actionable findings with severity and evidence. Review-only means do not edit files unless asked.
