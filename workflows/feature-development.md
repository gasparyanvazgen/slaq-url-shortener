# Feature Development Workflow

1. Confirm feature is in approved MVP scope.
2. Write or confirm acceptance criteria.
3. Read the relevant role card and design docs.
4. Inspect existing code.
5. Plan files and tests.
6. Implement one vertical slice.
7. Run tests and type-check.
8. Review diff and security implications.
9. Update docs and state.
10. Report actual results and deferred work.

A feature is not complete merely because code was generated.
