# MVP Release Checklist

- [ ] README setup instructions work on a clean checkout.
- [ ] Required Node/npm versions are documented and verified.
- [ ] No secrets or local database files are committed.
- [ ] TypeScript type-check passes.
- [ ] Automated tests pass.
- [ ] API examples match actual behavior.
- [ ] URL validation accepts only approved protocols.
- [ ] SQL statements are parameterized.
- [ ] Short-code uniqueness is database-enforced.
- [ ] Redirect status and click counting match the contract.
- [ ] Expired links behave as documented.
- [ ] Error responses do not expose internals.
- [ ] Known limitations and deferred features are documented.
- [ ] Git diff and status have been reviewed.
